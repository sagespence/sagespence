# Spencer Saxon

Software engineer and founder of [Saxon Foundry](https://saxonfoundry.com). Based in Miami.

I build web and mobile apps, internal tooling, AI systems and websites. Lately I spend most of my time on automated work that has to run unattended. That means spending limits, rollback, tests that have been shown to fail when they should, and a clear record of what happened.

## Projects

| Repo | What it is |
|---|---|
| [agent-safety-rails](https://github.com/sagespence/agent-safety-rails) | Design write-up of the guardrail layer I run around autonomous AI agents: checkpoint and rollback, action allowlists, an independent critic, model routing, bounded self-repair. |
| [llm-spend-guard](https://github.com/sagespence/llm-spend-guard) | Cost cap for LLM API calls. Refuses before spending, logs every call, and proves its own cap check can fail. |

| [roundseal](https://github.com/sagespence/roundseal) | Fingerprint a batch of file changes so it can be verified and restored by copy, never by replaying a patch. 81 tests. |
